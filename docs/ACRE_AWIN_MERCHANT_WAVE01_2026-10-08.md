# ACRE AWIN MERCHANT WAVE 01

Date: 2026-10-08
Mission: ACRE-FOUNDATION-001
Status: READY FOR FOUNDER SEARCH / MERCHANT-TERM REVIEW

## Objective

Create a small first advertiser wave inside Awin that strengthens real Acre Era lanes without turning the storefront into an affiliate-link directory.

## Selection doctrine

Awin itself recommends selecting advertiser programs based on audience need and program fit rather than indiscriminately joining everything available.

Public Awin materials currently identify 30,000+ brands globally and list examples including Samsung, Dyson, GE Appliances, SharkNinja, Nike, Under Armour, Uniqlo, and AliExpress.

Public/global listing is NOT proof that a specific U.S. advertiser program is available to this publisher account. Each program must be searched and reviewed inside the logged-in Awin publisher dashboard.

## Do not join blindly

For each visible advertiser, founder should review:
- geographic program / U.S. eligibility;
- commission rate and exclusions;
- attribution window;
- prohibited promotion methods;
- paid-search / trademark rules;
- social/content rules;
- deep-link / product feed support;
- return/cancellation reversals;
- merchant approval requirement;
- any externally binding terms.

## Founder decision point

The agent may research, shortlist, compare, and prepare integration.
The founder remains the authority for accepting merchant-specific terms and applying/joining programs.

## Next after approval

For accepted merchants:
1. bank merchant ID / status / program name without secrets;
2. map merchant to Acre Era lane;
3. qualify deep links / product feeds;
4. build explicit affiliate disclosure UX;
5. surface only real products/offers with merchant provenance;
6. measure click-through and conversion before expanding merchant count.
