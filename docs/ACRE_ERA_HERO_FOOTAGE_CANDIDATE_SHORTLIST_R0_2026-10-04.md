## Provider/API compliance notes

Pixabay currently permits free use, modification, and use without mandatory creator attribution under its Content License, subject to prohibited uses such as standalone resale/distribution.

Pixabay's API documentation also asks applications to show users where API-discovered media came from when displaying search results. Acre Era's admin workbench now provides a direct source link.

Pixabay allows video embedding directly but recommends storing approved video on our own server/infrastructure. Acre Era should therefore avoid treating temporary API search URLs as permanent approved assets.
